# MT4 初始交换探针

本实验用标准库 Go TCP 客户端，发送从本地真机样本单独提取的首次客户端 flight，并保存服务器初始响应。**它重放已采集的首段字节，没有实现握手生成、密码认证或账户读取。**

输入文件仅保存在 Git 忽略的 `.local/` 中，格式为：

```json
{
  "target": "<已从官方客户端连接中观察到的 IP:端口>",
  "initial_flight": "<首次服务器数据到达前的客户端字节，Base64>"
}
```

不要使用任意数据包或后续登录报文充当输入。字节长度限制只能约束实验大小，不能识别其语义。认证报文不能作为通用可重用的登录方式。

后续静态分析与独立实现已确认：**这段28字节首段包含账号和密码派生材料，并非匿名公共握手**。输入、响应及原始抓包均只在本地私有目录保存。此工具保留作早期重放实验；新验证使用[原生 Go 客户端](../../packages/mt4/README.md)，会按本地凭据重新生成首段和认证，不复用捕获会话。

在本目录运行：

```sh
go run . /absolute/path/to/private/probe-input.json
go vet ./...
```

探针限制连接时间和响应大小，终端输出连接状态及字节数。响应以 `0600` 权限写到输入文件同目录的独立 `probe-response-*.bin` 文件，已有文件不会覆盖。

本轮对两个已观察接入点分别发送对应的 28 字节首段，分别收到 832 和 856 字节；`authentication_verified` 均为 `false`。两个接入点的首段内容不同。该结果只证明捕获的初始交换可以由 Go 独立发起并得到响应，不能作为原生认证通过的依据。
