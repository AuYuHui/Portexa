# MT4 候选库传输复现

本实验调用 `digineat/go-metatrader4` 的真实 `Execute` 实现，连接本地回环响应器，观察第一帧数据。上游固定为提交 [`5a6b109a920acadda2c1b91cfa69333a71d5964f`](https://github.com/digineat/go-metatrader4/tree/5a6b109a920acadda2c1b91cfa69333a71d5964f)。

## 运行

需要 Go 1.26 或更新版本。进入本目录执行：

```sh
go test -count=1 -v ./...
```

首次运行会下载固定版本的依赖；协议实验只连接 `127.0.0.1`，使用源码中写明的虚构凭据，无需配置环境变量或账户。

## 验证内容

1. 客户端首帧直接发送明文 `WWAPUSER <Base64>\n`，随后发送 `QUIT\n`，此前没有认证或 TLS 握手。
2. 捕获的 Base64 可还原虚构账号和密码。
3. 本地响应器没有实现 MT4 登录，客户端仍可接受并返回其 Base64 响应。
4. 非法 Base64 响应会报错，证明实验确实经过响应解析。

**测试通过仅证明上述库行为，不能证明真实 MT4 服务器接受该命令，也不能证明账户登录、投资者权限或数据读取成功。** 本实验不推断 `WWAPUSER` 属于哪一种官方协议。

当前候选库缺少可用于真实账户验证的完整终端认证实现。请勿向本实验填写真实凭据；实际账户验证需待原生协议实现和服务器身份验证方式确认后进行。
