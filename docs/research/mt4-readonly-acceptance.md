## 浮动金额的对照方法

余额、信用、币种和保证金直接与官方显示精度比较。DLS 无持仓，净值也直接相等。DPrime、EC 的官方客户端持续收行情，而 SDK 是一次性账户快照；跨时刻直接比较净值和浮盈存在报价差值。

因此，活动账户的同一轮官方 UI 采样同时取买价、卖价、账户栏及可见订单。先检查同期持仓静态字段、余额及保证金一致，再使用每笔同步订单的价格/利润关系对齐官方买卖报价，核对可见利润和整户净值。两家均全部匹配，脱敏证据分别保留在本地 `*-price-aligned-ui-matches.json`。这属于同报价口径的实际核对，不是宣称两个不同时刻的原始净值恰好相等；当前没有实现实时行情订阅。

## 实现依据

账户主体仍为13824字节，订单为224字节。余额、信用沿用既有直接字段；新增币种与账户组规则、订单开平价格、转换率及语义时间字段。

- `Currency`：官方映射把账户主体 `+0x58` 的组配置复制到 `AccountInfoBase+0x278`；交易 UI 使用 `AccountInfoBase+0x3714` 的币种，映射到线格式 `+0x34f4`。
- `Equity`：同期余额 + 信用 + 当前 buy/sell 的利润、佣金、隔夜费和税费；挂单不计入持仓盈亏。对应官方客户端 `0x1000a4c0c` 的汇总路径。
- `Margin`：依据 `0x1000a4824` 的五种模式、加权开仓价格和转换率、杠杆、锁仓规则；`0x1000431a8` 的账户组覆盖决定实际品种除数。缺少配置、转换率或遇到未知模式时返回错误，不输出伪造的零保证金。
- 为上述保证金算术以合成输入离线执行官方函数，生成80组独立预期结果，覆盖五种模式、两种锁仓规则、初始保证金有无及单/双方向。公开测试只保留合成向量，不携带官方代码、模拟器或真实材料。
- 订单 `OpenTime/CloseTime`、`OpenPrice/ClosePrice` 对应既有记录偏移；手数按整数百分之一手转换。`Profit` 保留原始利润，`NetProfit()` 汇总单列费用。未进行账户币种转换。

## 历史完整性与重查

`--history-all` 请求0至2147483647，不再使用本机 UTC 当前时刻作上界，从而覆盖服务器墙钟超前的近期记录。`HistoryWindowSeconds` 支持相邻窗重叠一秒；相同订单号去重，后窗修订更新前窗，同页冲突则报错。返回按订单号排序，重复查询可直接比较。

**纠正历史研究的一处解释**：配置表 `0x08/0x0a` 带本地摘要，状态1表示未变化；历史 `0x22` 只带时间区间，状态1表示该区间为空。官方函数 `0x10003e868` 每次新建空数组，状态1分支 `0x10003e93c..0x10003e954` 将它交给 `0x1000a23e0`。本轮空区间实测与这条路径吻合。分窗空响应会正常提交空窗口，保留其余窗口的记录。

成功完成全部窗口才置 `HistoryRead/HistoryComplete=true`。中断、超时、拒绝、超限或坏记录都保留已成功的窗口与部分记录，并返回明确错误。不得用失败的部分结果覆盖持久化快照；业务存储仍由调用方按订单号更新，协议模块没有数据库依赖。

本轮三家固定过去区间分别做新会话重查与两窗查询，逐字段一致、无重复。另完成从0至协议时间上限的读取。服务器已经删除的历史无法恢复；16 MiB资源上限或20秒总期限触发时返回错误，不能将截断结果计作完成。本轮没有验证所有经纪商的服务端保留策略或所有规模的数据集。

## 只读与错误分类

三家的测试只使用本次用户明确提供的投资者凭据。SDK 要求 `PasswordType=InvestorPassword`，否则连接前拒绝；这是凭据类型声明，不是密码权限的独立证明。DLS 的原始投资者指示仍为0，另两家非零，不据此推断全部服务端权限，也没有通过交易尝试探测权限。

认证后只允许固定的配置、品种、分组、可选表、历史和账户查询形状，任何其他命令或畸形查询在加密、写入及流状态变化前被拒绝。公开接口没有交易入口；本轮未发交易命令。合成测试枚举256个单字节命令并验证拒绝路径无输出。

build 用于官方挑战分支和诊断，未设置逐券商或逐 build 白名单。兼容的新 build 直接复用相同 profile；合成未来 build1600 也通过相同公开接口。已知旧版挑战返回 `unsupported_build`，零挑战或未知能力返回 `unsupported_protocol`；未知布局和非法数据返回 `invalid_response`。这不代表未实测的未来版本已经获得兼容承诺。

`*mt4.Error` 保留脱敏的 `Code`、`Operation`、`ServerBuild`、原始 `Status`。其余分类为 `invalid_config`、`read_only_required`、`timeout`、`canceled`、`connection`、`server_rejected`、`resource_limit`。超时与取消保留 `errors.Is` 语义；失败阶段不会因取消而丢失。服务端状态不擅自解释成密码错误或权限拒绝。
