# MT4 服务器搜索与自动接入配置

默认流程为“搜索经纪商／服务器 → 选择候选 → 核对并确认接入”。IP、端口及来源摘要由系统取得；手动字段保留在高级入口。`packages/mt4` 保持冻结，发现功能位于主工程 `internal/discovery`。

## 来源和范围

使用 MetaQuotes 的 MT4 目录 `https://updates.metaquotes.net/public/mt4/network`，只提交搜索文字及目录兼容参数，不提交账户、投资者密码、会话令牌或设备资料。此目录是通过真实响应核对的客户端接口，不将其描述为有稳定性承诺的公开 API；格式变化或不可用时显示错误，不用第三方镜像静默替代。

[MetaTrader 官方帮助](https://www.metatrader4.com/en/trading-platform/help/userguide/open_an_account)确认了按经纪商名称搜索服务器的交互。请求格式参考公开目录客户端的[实现资料](https://github.com/voorz/mtapi/blob/main/search.go)，并独立验证 MT4 目录、`code=mt4` 和返回的原生地址；没有引入 MT5 库、WebTrader 登录网关或修改冻结 SDK。请求的兼容签名不承担 Portexa 登录认证或交易服务器身份认证。

目录响应可能在 JSON 前带有前导信息，本次实际响应为44字节，解析器接受有上限的前导信息并严格解析 `result`。公司及服务器来自目录，不根据名称猜测 IP；端口缺失的条目不猜为443。带端口的域名由服务端解析，过滤非公开地址，再固定具体 IP。

目录缺少某家经纪商、返回条目没有可用地址、网络失败均属于明确状态。当前只支持 MT4；目录查询成功不代表特定交易账户已通过 SDK 认证。

## 缓存和限制

- 查询为2至80个字符，拒绝控制字符；搜索按350毫秒防抖，输入变化取消旧请求。
- 上游固定为已登记的 HTTPS 来源，验证 TLS，不接受网页传入目标 URL，不跟随重定向。
- 单次请求预算12秒，响应最多2 MiB，同时最多2个目录请求。
- 每次最多返回200台服务器，每台最多24个去重后接入点；DNS解析次数及地址数另有限制。
- 内存缓存15分钟，最多32个查询且原文总计不超过8 MiB；不缓存失败，不用过期结果创建接入。
- 返回服务端生成的随机候选 ID；确认时重新读取候选，拒绝伪造或已过期 ID。浏览器不能覆盖 IP、端口、公司或来源摘要。

搜索接口要求系统登录，登记接口同时要求 Origin 与 CSRF。没有用户或角色扩展，也没有自动执行真实账户登录的目录接口。

## 登记与修订

候选来自独立于目标交易服务器的 MetaQuotes 目录。用户核对公司和服务器名称，并对当前所选接入点明确接受剩余风险后，原子保存服务器、固定接入修订、来源证据和确认时间。默认路径不再要求人工计算或抄写证据摘要。

这表示来源登记和用户确认已完成，仍不能证明原生交易连接具备密码学服务端身份认证。目录中的其他地址不会自动获得发送凭据的资格；固定地址不可用时不自动把投资者密码转发到另一个候选地址。

新修订必须同时匹配原服务器名称和经纪商公司，重新选择与确认。旧地址停用、相关账户暂停并取消旧任务，重新绑定后才恢复采集。高级手动路径保留原有的 pending → 独立证据核验及风险确认流程。

## 持久化与升级

迁移002新增 `server_directory_evidence`，以 SHA-256 为键保存目录来源、取得时间及响应原文；真实接入地址只存在于私有运行数据库和备份。它与接入修订在同一事务保存，不能留下部分已确认状态。数据库备份自动包含这些证据；密钥仍单独保管。

旧版 schema1 数据库启动时原子升级到 schema2，保留登录设置、会话、账户、快照和密钥绑定。恢复仍可读取 schema1 备份，在恢复后完成升级、撤销会话并暂停采集。没有隐式 ORM AutoMigrate 或破坏性降级。

## 验证

普通回归使用合成目录和受控 DNS，不查询真实交易账户。覆盖请求参数与编码顺序、目录前导格式、畸形/超限响应、重定向拒绝、非公开地址过滤、去重、缓存及过期、认证与 CSRF、候选不能由浏览器篡改、证据保存、跨服务器拒绝、新修订暂停，以及 schema1 升级和恢复。

```sh
GOWORK=off go test ./tests/discovery ./tests/app -count=1
make check
GOWORK=off go build -o .local/bin/e2e-server ./tests/e2e/server
# 启动上述合成 fixture 后执行：
.local/venv-browser/bin/python tests/e2e/discovery.py
```

浏览器验证包括桌面、390px手机、无匹配结果、候选选择、无需手填地址或摘要、明确确认、新修订及高级手动入口。真实目录验收只搜索公开经纪商/服务器元数据，不调用 SDK `Probe` 或 `Fetch`；原始目录响应保存在被忽略的私有目录，不能提交到代码或测试。

2026-11-11 的 Go 客户端实测可搜索 DPrime、IC Markets、ECMarkets 和 DLSMarkets；精确搜索 `DPrimeVU-Live 9` 取得7个可用候选地址。这是当次目录结果，不作为固定数量承诺。本地产品接口也已验证该搜索，升级保留原有登录密码、会话、账户配置和密钥；未登录真实交易账户。
