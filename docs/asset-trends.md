# 资产历史与净值走势（WP2）

总览在资金卡片下、账户列表前展示历史组合估值；账户详情展示余额与净值曲线。两处共用图表组件，支持24小时、7天、30天、90天及自定义区间，切换净值、余额或双指标。工具栏状态保存在 URL，刷新和浏览器前进、后退可复现所选范围。

资产曲线包含出入金和信用金变化，不代表交易收益。资金流调整后的收益率、最大回撤与收益日历仍属于后续 Analytics。

## 账户曲线

- 默认原币；USC 保持美分金额。有已确认 USD 换算样本时可切换美元视图，使用对应快照保存的倍率，金额不提前舍入。
- 历史范围出现多个币种时，按币种选择查看；不同单位版本不连接。后来的单位配置不覆盖旧快照。
- 横轴使用快照实际完成的 UTC 毫秒时间，界面明确按北京时间 UTC+8 展示；与 MT4 服务器日统计分别解释。
- 净值包含信用金；悬停、触摸或点击时点查看余额、净值、信用金、浮动净盈亏、实际采集窗口及数据状态。历史明细采用同一组后端采样点，每页20条。
- 首次成功前和请求区间外保持空白，单个样本显示单点，不用成交历史还原接入前权益。

新快照保存发布时的后台采集周期。相邻样本完成时间之差超过两端周期较大值的3倍、且至少3分钟时分段；币种或单位版本改变也分段。旧快照的历史周期保持未知，以独立点展示，不套用当前设置猜测过去的连续性。

图表金额只为坐标渲染转换为 JavaScript 数值；财务计算、悬浮提示和明细使用后端 Decimal 字符串。超出安全绘图范围的金额保留明细，不绘制错误坐标。

## 组合曲线

范围为已有效纳入的 USD / USC 账户，统一为 USD。成员从账户保存的 included_at_ms 开始，到 removed_at_ms 结束；暂停采集不等于移出。未取得首次有效纳入快照的账户单列为待纳入，其他币种和未确认单位单列说明，不把它们当零加入合计。

每个 UTC 整分钟选择各成员在该点之前完成的最近快照，要求：

1. 每个必要成员都有样本，完成时间距该点不超过90秒。
2. 各采集窗口的并集跨度不超过90秒。
3. 样本有已确认的美元倍率，且与该时点生效的单位版本一致。

不满足条件时金额为 null，展示缺失原因，不拼接不完整小计。120、300秒采集档位可能产生较多空白分钟，保留这一结果，不放宽90秒标准。新账户不会被历史回填加入过去的组合；纳入、移出及单位变化使曲线分段，并提供成员事件标记。

WP2 原始资产估值依据成功快照，不因交易历史正在回填而隐藏。它不计算区间利润；后续收益分析仍须满足历史覆盖、资金分类及对账条件。

## 资金事件

仅标记已发布当前修订中，分类为外部入金或出金、单位可解释、服务器墙钟能唯一还原 UTC 的记录。人工分类只对匹配的来源修订生效；自动分类使用当前规则。信用、费用、内部转账和待分类记录不标成出入金。

时间规则按版本的生效范围解释；未核验、过期的观察偏移、夏令时重复或不存在的墙钟不猜测。一次请求最多检查500条候选资金记录；超限或未能定位时明确说明，标记缺失不代表没有资金流。成员事件与出入金分别标注。

## 查询接口

均要求已有登录会话，金额为十进制字符串，缺失为 null，响应为 Cache-Control: no-store：

    GET /api/accounts/{id}/equity-history?from_ms=…&to_ms=…&unit=native
    GET /api/accounts/{id}/equity-history?from_ms=…&to_ms=…&unit=USD
    GET /api/portfolio/equity-history?from_ms=…&to_ms=…&unit=USD

时间为 UTC 毫秒，范围为 [from_ms, to_ms)，最多90天。拒绝未知参数、重复参数、非法单位及未来区间。不存在的账户返回404，匿名访问401，查询超时503。单次查询上限15秒，浏览器切换范围时可取消旧请求。

返回 points、events、请求范围、生成时间、有效/缺失点数、连续性分段、单位、采样方法、过期状态和未纳入说明。每点保存实际采集窗口及应纳入/已采样账户数。空数组与 null 不兼任已知零值。

服务端以300个时间桶保留首尾、余额与净值各自极值，以及缺失点，去重后最多2400条。先识别原始分段，再采样；抽样不能连接两个不连续片段。组合先完成每分钟的成员与时差校验，再降低展示点数。明细代表所展示的采样数据，不是完整原始快照导出。

SQLite 按账户、完成时间及快照 ID 分页读取；组合使用分钟索引选择该分钟可用的最后一条原始样本。整数时间可以分桶，金额 TEXT 不转 REAL，也不在数据库中平均余额或净值。每批最多2048行，关闭游标后再计算和输出；不修改原始数据。

预设范围每60秒刷新，固定自定义区间按需读取；有效范围缓存可复用，手动刷新可强制查询。图表使用 Apache ECharts 按需加载，提供时间滑块、拖选缩放及还原；手机工具栏换行，图表高270px。

## 迁移与运行边界

迁移008增加快照采集周期、组合分钟索引及 account_unit_changes。新账户和单位变更在原事务中记录版本生效时间；快照及持仓发布保持原子性。旧周期保持 NULL，旧单位版本保留原始快照证据；历史未知变更时间不填造。

迁移不重新加密凭据、不撤销有效会话、不修改账户金额。升级前按[启动与管理](product-start.md)备份；回退使用匹配旧版本的备份，不尝试就地降级 schema8。真实运行目录不由普通回归访问或升级。
