# 收益与风险分析

Analytics 位于侧栏“收益分析”。四个区域依次为收益与风险 KPI、收益表现、收益日历及账户贡献。支持组合或单账户、24小时/7天/30天/90天与自定义范围，中英文与手机布局；筛选保存在 URL。

## 统计范围与金额

- 默认全部已有效纳入的 USD / USC 账户，美元美分按已确认倍率换算；其他币种可选单账户原币分析，不能直接相加。
- 日历与日期输入使用北京时间。账户页面既有“当日”仍按 MT4 服务器日期，两者分别标注。
- 请求区间最多90天，向内对齐至完整 UTC 分钟边界，至少两个相邻分钟时点。历史记录按 `[开始,结束)` 归属，端点资金事件另做估值歧义检查。
- 截止时间取可用历史成功运行的开始时间与有效快照的公共分钟边界，不能将请求的当天终点或同步完成时间当作已经发生的数据。页面同时显示实际范围与生成时间。
- 金额使用 Decimal 与十进制字符串；不在前端、SQLite REAL 或金额 TEXT 的隐式加总中计算。原始金额不提前舍入，收益率除法及每步复合明确保留24位小数。

## 四个 KPI

统计权益 `V = Equity - Credit`，保留 SDK 原始含信用金净值供账户页展示。

| 指标 | 口径 |
| --- | --- |
| 区间净收益 | `V_end - V_start - 资本净流入`；包含浮盈变化 |
| 已实现交易净盈亏 | 区间平仓买卖记录的 `Profit + Commission + Swap + Taxes` |
| 估算收益率 | 连续有效分钟区间按 Modified Dietz 计算，再复合连接 |
| 采样最大回撤 | 所选区间资金流调整曲线从此前峰值到后续谷值的最大跌幅 |

资金流加权公式为 `r = (V_end - V_start - ΣK) / (V_start + ΣwK)`，其中 `w = (t_end-t_event)/(t_end-t_start)`。累计收益率为 `Π(1+r)-1`。没有资金流时点的准确估值，不称为精确时间加权收益率。

归一化曲线从1开始；回撤为 `1-N/此前最高N`。峰值、谷值及恢复时间随结果提供，零回撤不制造峰谷事件。分母非正、收益率小于等于-100%或复合链失效时停止相关百分比，金额事实仍独立判断。

净收益分解为已实现交易净盈亏、浮动净盈亏变化、已确认返佣/分润收入和独立费用/分润支出。使用浮盈的期末减期初变化，不能直接加期末浮盈。

## 资金分类与组合

外部入金、出金、确认的资本性调整和成员纳入属于资本变动；信用金通过统计权益剔除。返佣、费用、分润属于收益或成本，不能再次当作资本剔除。未知流水和“其他调整”仍待确认；资金校正入口新增“已确认资本性调整”，需填写依据。

单账户的内部转账按资本进出处理。组合内转账必须人工核对两个不同账户的当前来源版本、方向、分类版本、时间规则及换算后的相等金额。转出不能晚于转入；混合费用需先拆清。匹配证据只追加保存，来源、分类或时间规则变化后旧匹配失效。

已确认且双方均属于组合的转账，在转出至到账之间作为已知在途资金计入组合统计权益，不能制造亏损或回撤。查询起点之前发起的转账也检查，不能因切换期间而丢失在途金额。未配对的已知内部转账阻止相关组合净收益和百分比，已确认平仓盈亏保留。

新账户按其纳入时间及首份可验证快照建立资本流入，不回写此前组合。暂停采集不是移出。现有移出记录缺少可核验退出估值时，受影响净收益和百分比保持不可用，不猜测退出金额。

## 对账与完整性

每个 UTC 分钟只选择该点前完成的最近样本，样本年龄及采集窗口跨度都不得超过90秒。组合要求所有当时必要成员齐全。未知历史采集周期、单位版本变化、缺失样本和采集偏差均有明确原因。

统计先从原始快照构建分钟估值，绝不使用资产走势图的抽样结果；完成计算后才降低图表点数，保留端点、指标极值和连续段标识。图表遇到不同连续段必留空。缺口后的曲线是重新归一化的片段，不冒充完整区间指标。120/300秒采集可能产生较多空白分钟，不放宽标准。

资金事件具有秒级时间精度。事件落入快照采集开始前999毫秒至该分钟标签之间时，不能确认其是否计入边界估值，该点保持不确定。

余额变化与已入账交易净额、余额流水核对；信用金变化与信用流水另核对。初始金额容差为每户 `0.00000001` 原币，按单位倍率换算，组合累加容差。对账差额、容差及状态随结果提供，不把差额补作收益或出入金。经纪商的费用入账语义若与当前模型不符，会保留差额并阻止相关指标。

SDK 的 Equity 是由余额、信用金和持仓计算的值，结构恒等式仅是内部一致性检查。未与独立券商报表核对的来源，不声称已经独立核验。历史完整也仅表示服务端可返回范围内成功发布的完整响应，不能证明已删除历史完整。

| 情况 | 处理 |
| --- | --- |
| 历史缺失或历史时间不确定 | 完整交易统计不可用，不能记零 |
| 待分类资金 | 平仓盈亏可独立展示，净收益及未确定的资金/成本小计不可用 |
| 中间快照缺失，端点与资金流水可靠 | 净收益金额仍可核对；完整收益率和回撤不可用 |
| 无有效期初或期末估值 | 净收益不可用；完整已实现盈亏仍可用 |
| 完整区间无平仓 | 已实现盈亏和笔数为0 |
| 日历不具备完整交易依据 | 平仓笔数为 null，显示待核验 |
| 没有组合成员 | 指标不可用，不生成空组合的零收益 |

日历点击日期可查看收益分解和交易/资金流水，每页50条。月份净收益只加总所选月份内已完整核对的日期；任何日期不可用时月份值也不可用，区间首尾的部分月份明确标记。

账户表同区间、同截止、同方法排序，缺失值排在可比较结果之后。组合收益率及回撤独立计算，不平均或相加账户百分比。

## 来源证据与查询接口

所有接口要求登录，响应不缓存。修改转账配对还要求 Origin 和 CSRF。

    GET /api/analytics?from_ms=…&to_ms=…&unit=USD
    GET /api/analytics?from_ms=…&to_ms=…&account_id=…&unit=native
    GET /api/analytics/activity?from_ms=…&to_ms=…&offset=0&unit=USD
    POST /api/analytics/transfers

范围参数不接受未知或重复字段。分析查询限15秒，超时503；当前修订在分批读取期间变化返回409，不发布混合版本结果。最多读取200,000条候选历史记录，超限明确报错，不截断后继续计算；流水明细限一天。

结果包含各指标的值和原因、实际范围、数据状态、对账、采样数、计算版本、来源版本和 SHA-256 证据摘要。摘要引用当前订单、有效分类、时间规则、快照和转账依据；相同依据及区间得到相同摘要。诊断的生成时间不参与收益计算。

迁移009扩充资本调整分类，保存转账核对和分析依据修订。升级不改变现有金额、凭据或会话。升级前按[启动指南](product-start.md)备份；回退使用匹配旧版本的备份，不就地降低数据库版本。普通回归只操作合成数据库。
